# Homebrew tap for Magic Switch

[Magic Switch](https://github.com/MegaManSec/magic-switch) is a menu bar app that moves Magic Keyboard, Magic Trackpad and Magic Mouse between two Macs.

```sh
brew install --cask megamansec/tap/magic-switch
```

The cask is updated by Magic Switch's release workflow, which checks each release's build attestation before committing the new version here. Report problems at [MegaManSec/magic-switch](https://github.com/MegaManSec/magic-switch/issues).
